# T17: まとめカード C6 の折り返しを直して動画を再生成(YouTube アップロード前の最終版)

## 目的
カード C6 の 1 行目が「…と同じ 3 層構 / 造をシムで再現…」と単語の途中で自動折り返しされている。行を明示的に区切って直し、提出動画を作り直す。ほかのカード・ショットは変えない。この版を YouTube にアップロードする。

## 手順
1. `scripts/make_cards.py` の C6 を、自動折り返しに頼らず次の 4 行に明示的に分ける(数値・URL は変えない):
   - 「実機 Go2 と同じ層構造をシミュレーションで再現」
   - 「自己位置 → 地図・計画 → 速度指令 → 歩行(2D → 3D LiDAR)」
   - 「限界: 真の姿勢を使用(SLAM なし)、静止障害物、非決定性」
   - 「コード: github.com/raycast-trail/go2-genesis-patrol」
2. **全カード・全バナーを目視で確認**し、ほかにも単語・数値・括弧の途中で折り返している行があれば、同じく明示的な改行で直す(文言は変えない)。直したカードを報告に列挙
3. `python scripts/check_margins.py`(全 OK であること)
4. `python scripts/make_video.py`(T16 と同じ引数)で `videos/final/PAI最終課題_3164.mp4` を上書き。長さが T16 と同じ(約 168.8 s)であること。`results/t10_contact.png` を更新
5. 個人情報の検査(T16 手順 1-6 と同じ grep、ffprobe のメタデータ)
6. コミットし、push の前だけ `gh auth switch -u raycast-trail`、push 後に元のアカウントへ戻す
