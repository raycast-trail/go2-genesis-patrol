# T09: 占有格子地図 + A* 大域計画(v3)— 期限 10/24、未完なら切り捨て

## 目的
v1(振動)と v2(遠回り)のトレードオフは、反応的回避が「障害物の向こう側」を知らないことに由来する。LiDAR スキャンから **2D 占有格子**を作り、その上で **A\*** により次のウェイポイントまでの経路を計画して、経路追従のローカル目標を与える(v3)。反応的回避(v1)は安全停止として下層に残す。実機 Go2 の「自己位置推定 → costmap/planner → 速度指令 → 歩行」の 3 層構造が揃う。

**これは余力タスク**。10/24 中に受け入れ条件を満たせなければ、その時点の結果と考察を `reports/09` に書いて止める。提出物(動画・レポート)は v1/v2 で確定しているので、v3 は「載せられたら載せる」。

## 設計(最小構成)
- **地図** `nav/grid_map.py`: 分解能 0.05 m、範囲 x,y ∈ [−2, 4] m(120×120)。log-odds 更新: 地面除去後のヒット点のセルを +0.85、センサからヒット点までのレイ上のセルを −0.4(Bresenham)、max_range のレイは空きのみ更新。クリップ ±5。占有判定 > 0.5、未知 = 0(通行可として扱う。実機 costmap の慣習)
- **膨張**: 占有セルを Go2 の半径 0.35 m 分(7 セル)膨張。膨張後のセルは通行不可
- **計画** `nav/planner.py`: 現在位置 → 次のウェイポイントへ A\*(8 近傍、対角 √2、ヒューリスティックはユークリッド)。経路が見つからない場合は「未知も不可」ではなく「膨張半径を 0.25 m に縮めて再試行」、それでも無ければ直線(= v1 と同じ挙動)
- **ローカル目標**: 経路上で現在位置から 0.8 m 先の点を `WaypointFollower` の一時目標にする(到達判定はウェイポイント本体のみ)。**1.0 s ごと(50 ステップ)に再計画**
- **下層**: v1 の反応的回避をそのまま適用(停止距離 0.45 m は変えない)。計画がある分、発動は減るはず
- 真の姿勢を使う(SLAM なし)。これは明記する

## 手順
1. `nav/grid_map.py`、`nav/planner.py` を実装。単体テスト `eval/map_test.py`: T02 の既知配置(Box 正面 1.3 m、Cylinder 右)で立位 100 ステップ → 地図を PNG(`results/t09_map_test.png`)に出し、Box と Cylinder の位置に占有セルが出ていることを確認
2. `go2_patrol.py` に `--avoid-version v3` を追加(v3 = 地図 + A\* + v1 下層)。`--mcap` 使用時は `/map` を `Grid` スキーマで 1 s ごとに書き出す(Foxglove で地図が見える)
3. seed 12, 25, 26, 28(v1/v2 の失敗配置)で v3 を実行(俯瞰寄せ、録画)。軌跡図に計画経路(最終再計画時)を重ねる
4. 45 配置 × v3 を `results/eval_50/` に追加(`--avoid-version v3`、約 25 分)。`summarize.py` を 4 条件対応にし、v3 vs v1 / v3 vs v2 の McNemar と所要時間比較を追加
5. `videos/raw/v3_seed28_close.mp4` を収録(動画の差し替え候補。差し替えは人間が判断)
