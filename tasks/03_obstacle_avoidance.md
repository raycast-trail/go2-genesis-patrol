# T03: ランダム障害物シーンと回避則(T01・T02 完了後に着手)

## 目的
障害物のあるシーンで、LiDAR のセクタ距離に基づく反応的な回避を経路追従に加え、正方形巡回を 1 周させる。設計書 §3.3–3.4。

## 手順
1. `eval/scenes.py`: `make_obstacles(seed, n_min=3, n_max=6, area=(-0.5, 2.5)) -> list[morph]`
   - 2 m 角の正方形経路(ウェイポイント (2,0),(2,2),(0,2),(0,0))の **周辺** に Box(0.3〜0.5 m 角、高さ 0.5)と Cylinder(半径 0.1〜0.2、高さ 0.6)を乱数配置
   - 制約: ウェイポイントから 0.5 m 以内、初期位置 (0,0) から 1.0 m 以内には置かない。障害物同士は 1.2 m 以上離す(Go2 が通れる幅を確保)
   - `seed` で完全に再現可能。配置を `results/scenes/seed_NN.json` に保存
2. `nav/avoid.py`: `ObstacleAvoider`
   - 入力: `sector_min(12)`、経路追従が出した (vx, ωz)
   - 規則(反発ベクトル法の簡易版):
     - 正面 3 セクタ(−45°〜+45°)の最小距離 `d_front`
     - `d_front < d_slow(1.0 m)`: vx を `vx * (d_front - d_stop) / (d_slow - d_stop)` に減速
     - `d_front < d_stop(0.45 m)`: vx = 0(安全停止)、その場旋回
     - 左右の空き(左 3 セクタ vs 右 3 セクタの最小距離の大きい方)へ ωz を `k_avoid * (1 - d_front/d_slow)` だけ加える(符号は空いている側)
     - ωz の変化率制限: 1 ステップあたり ±0.1 rad/s(急な指令変化で転倒させない)
     - 出力は学習時の指令範囲内にクリップ(vx [0, 0.8], ωz [−0.8, 0.8])
   - パラメータはすべて引数(既定値は上記)。レポートに最終値を記録
3. `go2_patrol.py` に `--seed`(障害物シーン、`-1` で障害物なし)と `--avoid/--no-avoid` を追加。衝突判定: 地面除去後の LiDAR 最小距離 < 0.25 m を **collision** として記録(ステップ数と最初の発生時刻)。ログ CSV に `min_dist`, `collision` 列を追加
4. seed 0, 1, 2 で `--avoid` を実行し、動画(`videos/t03_seed{N}.mp4`、俯瞰カメラ: pos=(1,-4,4), lookat=(1,1,0))と軌跡図(障害物を描き込む)を出す
5. 同じ seed で `--no-avoid` も実行し、衝突が起きることを確認(比較用)

## 受け入れ条件
- [ ] seed 0, 1, 2 の 3 配置で `--avoid` が **4/4 到達・衝突なし・転倒なし**(60 s 以内)
- [ ] 同じ 3 配置で `--no-avoid` は少なくとも 1 配置で衝突または未到達(回避の効果が示せる)
- [ ] `results/t03_traj_seed{N}.png`(障害物と軌跡)、`reports/03_obstacle_avoidance.md`(パラメータ最終値、各 seed の到達数・衝突・所要時間の表)

## 調整候補(最大 2 つ)
1. `d_slow` 1.0 → 1.5、`k_avoid` を上げる(回避開始を早く)
2. ウェイポイント到達判定 `reach_dist` 0.3 → 0.4、巡回経路を 2 m 角 → 2.5 m 角(余裕を持たせる)
